# Guia de Matrices en C

Esta carpeta contiene los 19 ejercicios de la guia de matrices, separados en
archivos `.c` independientes. Cada archivo explica su funcionamiento, indica
los tipos de datos usados y contiene `system("pause")` para Windows.

Para compilar un ejercicio:

```text
gcc 01_copiar_multiplicar.c -o 01_copiar_multiplicar.exe
```
